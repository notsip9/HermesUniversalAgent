# Changelog

## 0.4.0 - Windows desktop preview (development)
- Reconstructed the application source project from the published 0.3.0 product documentation.
- Added local stdio MCP server and settings application.
- Added default-deny desktop interaction and separate screen-capture permissions.
- Added window enumeration/focus, coordinate click, and bounded text typing tools.
- Added automated tests and Windows CI/build workflow.
- This is a reconstructed preview and is not yet a replacement for the 0.3.0 release.

## 0.3.0 - 2026-11-15
- First prepared Windows x64 portable binary release.
- Local stdio MCP server with seven tools.
- Workspace listing and UTF-8 text reading.
- Optional workspace writes, disabled by default and requiring explicit confirmation.
- Local SQLite memory save and search.
- Windows settings utility.
- Proprietary binary distribution; source code was not included in the binary release.
