# Privacy notice

Hermes Universal Agent 0.3.0 is designed to run locally on Windows. Its settings and memory database are stored on the user's computer under %LOCALAPPDATA%\HermesUniversalAgent.

The MCP server reads and writes only within the workspace configured by the user. Memory notes are stored in a local SQLite database.

This release does not include a hosted account service or a cloud memory service. When an MCP client invokes a tool, information returned by that tool is available to that client and may be processed according to that client's own privacy policy.

The publisher has not made a claim that every possible third-party MCP client is private or secure. Review the connected client's data handling before use.
