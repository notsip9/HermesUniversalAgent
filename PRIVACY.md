# Privacy notice

Hermes Universal Agent is designed to run locally on Windows. Settings and the memory database are stored on the user's computer under %LOCALAPPDATA%\HermesUniversalAgent.

The MCP server uses a local standard-input/standard-output process. It does not implement a hosted account service, cloud memory, telemetry, or a remote control endpoint.

Workspace tools access only the locally configured workspace. Memory notes are stored in a local SQLite database. Desktop features are optional and disabled by default. If enabled, screen captures, window titles, mouse actions, or keyboard input may be returned to the connected MCP client. That client may process the information according to its own privacy policy.

The publisher does not claim that every third-party MCP client is private or secure. Review the connected client's data handling before use. Do not enable screen or input permissions unless you understand which client will receive the resulting information.
