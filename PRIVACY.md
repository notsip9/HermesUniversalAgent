# Privacy notice

Hermes Universal Agent is designed to run locally on Windows. Settings and local SQLite memory are stored under `%LOCALAPPDATA%\\HermesUniversalAgent`.

Workspace tools operate within the configured workspace. Desktop window metadata, screenshots, mouse clicks, and typed text are exposed only when the corresponding local permission is enabled and the relevant MCP call is explicitly confirmed. Information returned to an MCP client may be processed under that client's own privacy policy.

Hermes does not include a hosted account service, cloud memory service, telemetry service, or background screen-monitoring service in this preview.
